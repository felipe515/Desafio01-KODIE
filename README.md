# 🏋️ Center Fit Academia

Landing page responsiva desenvolvida para uma academia fictícia chamada **Center Fit Academia**.

O projeto foi desenvolvido com foco em praticar estruturação semântica com HTML5, estilização com CSS3, responsividade e acessibilidade.

---

## 📌 Sobre o projeto

A Center Fit é uma landing page para uma academia moderna, com o objetivo de apresentar seus serviços, estrutura, equipe e formas de contato.

A página foi desenvolvida pensando em uma experiência simples, moderna e responsiva para diferentes tamanhos de tela.

### Seções presentes

- Hero com chamada para ação (CTA)
- Sobre a academia
- Serviços e modalidades
- Galeria de imagens
- Equipe de profissionais
- Depoimentos de alunos
- Contato
- Redes sociais
- Footer

---

## Como a IA ajudou

A IA foi utilizada para:

- Gerar imagens relacionadas ao conceito da academia;
- Criar referências visuais para o projeto;
- Auxiliar na estruturação semântica do HTML;
- Sugerir estilos CSS;
- Auxiliar na criação de um layout responsivo;
- Identificar e corrigir problemas de enquadramento das imagens;
